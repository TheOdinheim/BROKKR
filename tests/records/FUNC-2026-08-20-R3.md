## What the tests establish about the cycle

- **Deny-at-any-gate short-circuit** (tests 2, 3, 4, 10): the first gate to deny returns `Denied{stage}` and the later subsystems are provably not consulted (spy call counts are 0 downstream).
- **Execute only on a full clear** (test 1): the tool runs exactly once, only when BIFRÖST + REGIN + SINDRI + HÚÐ all pass.
- **Live reconciliation feed** (test 5): `Observation::Hop { executed: Some(..) }` reaches HEIMDALL — the mechanism Phase 8 built with `executed: None` now receives a real executed action.
- **`now` per call, no held clock** (test 8): two different `now` values in the same orchestrator instance; both hops behave identically and independently.
- **SAGA records the decisions** (tests 1, 9): the proposal (step 3), the gate verdict (step 5), and — on a firing detection — the raised signal (step 8), which is also routed to EIR/KVASIR.
