## Source facts confirmed

- **SAGA end-truncation vs middle-deletion** — `verify_chain` checks each present record's `prev` + signature; it has no expected-length notion, so an end-truncated prefix verifies `Intact`. (14A confirmed a *middle* deletion is `Broken`.) Basis for F-30; test uses real `Saga::new` + `append`×10 + `from_records(take 7)` + `verify_chain`.
- **F-13 eviction target** — `check_guards` evicts the smallest-expiry entry at cap; a still-fresh target given the smallest expiry is the deterministic eviction. Basis for F-29.
- **Content-blind audit** — `ProposalRecord` records the action `detail` + sanitized rationale; no event records `ToolOutcome.output` or written bytes. Basis for F-31.

## Findings (documented, not fixed)

- **F-29** (LOW) — the F-13 nonce-ledger cap opens a bounded replay window (nonce-space exhaustion evicts a still-fresh target). Bounded by SINDRI Signal-2 expiry and by DAP control of chain generation.
- **F-30** (INFO) — SAGA end-truncation is undetectable by `verify_chain` alone; needs an external length witness (OQGF-R-5 replica / sequence checkpoint). In-memory today, so not realizable in this build.
- **F-31** (INFO) — content-blind auditing: the action is recorded, its effect (tool output / written content) is not. By design (spine governs authority, not content).
