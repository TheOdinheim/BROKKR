## Known limitation (flagged)

**ctrl-c / SIGINT is not wired to the KillSwitch.** `ctrlc` is unavailable offline (an `--locked`
build would fail adding it) and raw signal handling needs `unsafe` (forbidden in `brokkr-cli`, §6).
The KillSwitch mechanism — checked before every gate, model-unreachable (P-12.5) — is fully wired and
is triggered by the `kill` REPL command (→ the next hop is `[killed]`). Only the SIGINT *delivery* is a
`kill` command rather than a signal handler. Referred to the DAP: add `ctrlc` (vendored) if a real
SIGINT handler is wanted, or accept the `kill` command.
