## brokkr-reasoner tests (6)

- `test_propose_with_cleared_context_produces_proposal` — a mock backend returns a valid response;
  `propose` wraps it as a `Proposal` with the reasoner's hop; `endpoint()` returns the registered id.
- `test_propose_does_not_hand_cleared_context_to_backend` — the mock backend records its payload;
  asserts it received exactly the cleared text (structurally the backend signature is `&str`, so the
  `ClearedContext` token cannot be passed).
- `test_backend_error_maps_to_reasoner_error` — a failing backend → `ReasonerError::Backend`.
- `test_i12_propose_requires_cleared_context` — runtime path with a genuinely-cleared context; the
  compile-time proof is the `brokkr-core::reasoner` `compile_fail,E0308` doctest (still passing).
- `test_unregistered_endpoint_refused` — `Mimir::new` against an unregistered endpoint →
  `UnregisteredEndpoint`.
- `test_end_to_end_real_bifrost_clears_then_proposes` — a **real** `brokkr_bifrost::Bifrost` clears a
  Public context (via HÚÐ), then MÍMIR proposes on the resulting `ClearedContext` (I-12 end-to-end).

## brokkr-tools tests (2 + 1 doctest)

- `test_authorized_action_executes` — a stub tool receives an `AuthorizedAction` (minted the
  sanctioned way, via a `CostimulationGate` double, core only) and returns a fixed result.
- `test_tool_does_not_reauthorize` — the tool executes on a received `AuthorizedAction`; nothing in
  `brokkr-tools` mints one or calls `authorize`.
- doctest (`lib.rs`, `compile_fail`) — forging an `AuthorizedAction` in a tool does not compile.
