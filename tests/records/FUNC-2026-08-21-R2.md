## Test-infrastructure notes

- **Real SINDRI** with real `DualKeyPair`s and controlled `RegistryResolver`/`TestGenome`; **real BIFRÖST/HÚÐ** for the classification test (4.1); spy doubles for MÍMIR (the attacker's puppet), tool, SAGA, HEIMDALL, signals.
- **The spy tool never touches the filesystem** — records the call + detail length only — so the path-traversal and 10 MB attacks are safe.
- **All chains signed once, serially, in a single `OnceLock` fixture.** This is both a speed optimization (real SLH-DSA signing ~4s each) and a **correctness requirement**: a first draft that shared one keypair for concurrent signing across parallel threads produced corrupted signatures — the F-4 backend finding (`brokkr-crypto` `unsafe impl Sync` + `sign_dual(&self)` permits a signing data race). Verification is thread-safe (each `resolve` mints its own verify-only key), so tests still run in parallel.
