| F-34 | MEDIUM | `EgressRule` declares port+protocol (P-12.4) but `Destination::Network` has neither; `check_egress` is **host-only** — port/protocol structurally unenforceable. |
| F-35 | LOW | Egress host match is exact-string: `127.0.0.1 ≠ localhost`; `"*"` is a literal, not a wildcard. |
| F-36 | LOW | Kill flag is a resettable `AtomicBool`, **not a latch** — reset resumes operation. |
| F-37 | LOW | Kill flag is a **pre-hop** check, not a mid-hop abort (by design, ARCH §6.13); latency bounded by the longest tool call. |
| F-38 | LOW-INFO | Trajectory is **in-memory only** (`Mutex<Vec<..>>`), not a SAGA event; durable reconstruction rests on the SAGA event stream. |
