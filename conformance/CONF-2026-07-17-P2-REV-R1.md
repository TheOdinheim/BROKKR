## 2. The M-8 subtlety, stated plainly (§7)

This revision makes public-key-only verification **available**. It does **not** by itself
change `brokkr-intent`'s `verify_chain`, which still takes a `DualKeyPair` — switching it to
`DualPublicKey` with attestation-sourced public keys is **Phase 4** (SINDRI verifies chains it
did not sign, using public keys from OQGF-M-1 attestations). Therefore the **M-8 verdict in
the Phase 3 record `CONF-2026-07-16-P3-R1` stays `partial`** until Phase 4 wires it. What this
revision does is **remove the blocker** (the missing type) — logged in `risks/REGISTER.md`
RISK-2026-0003, now `Reduce`/Executed with the wiring residual carried to Phase 4.

## 3. FFI honesty (§7) and unsafe confinement (§6) — re-verified

- **New symbols are the real exported ones.** `nm -D` shows `wc_MlDsaKey_ExportPubRaw`,
  `wc_MlDsaKey_ImportPubRaw`, `wc_SlhDsaKey_ExportPublic`, `wc_SlhDsaKey_ImportPublic` exported;
  the linked test binary imports exactly those (`nm -u`) and **zero** `dilithium`/`falcon`/
  `kyber` symbols. Prototypes matched to the v5.9.2 headers.
- **Sizes probed, not guessed.** ML-DSA-65 public = **1952 B** (`WC_MLDSA_65_PUB_KEY_SIZE`),
  SLH-DSA-SHAKE-192s public = **48 B** (`wc_SlhDsaKey_PublicSizeFromParam`), from a C `sizeof`/
  size-query probe against the real headers+`.so`.
- **Fail-closed import.** `from_public_bytes` validates the input length against the pinned
  public-key size and rejects a mismatch (`CryptoError::MalformedKey`) — proven by
  `test_malformed_public_bytes_rejected`. A malformed attestation key does not sail through.
  Verification is additionally proven keyed on the **full** public-key bytes (not merely
  length-gated) by `test_tampered_public_key_fails_verification`: a valid-length,
  middle-byte-flipped public key never both imports and verifies.
- **Non-FIPS unchanged.** No new FIPS claim; posture remains `CRYPTO_POSTURE` verbatim.
- **Unsafe still only in `ffi.rs`** (44 constructs); `hash.rs`/`lib.rs`/`shred.rs`/`sign.rs`
  = 0. Raw pointers/structs do not escape `ffi.rs`; every new `unsafe` block carries a
  `// SAFETY:` comment.
