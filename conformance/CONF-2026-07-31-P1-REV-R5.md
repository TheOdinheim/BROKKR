## 2. The finding-identity properties (the load-bearing part)

`finding_id()` is a **pure function of `(datum, condition)` only** — never `classification`, `reason`,
a counter, or a clock — so a DAP can compute it and issue an acceptance **before** the crossing is
attempted (§6.5). It lives in `brokkr-core`, so the Barrier and any acceptance-issuing tool compute it
identically. The encoding is `"<len>:<datum>:<condition-tag>"` with `<len>` the datum's byte length;
the length prefix (not a delimiter) bounds the datum, so a `DatumRef` containing a `:` cannot absorb
the separator or the tag — the map `(datum, condition) → FindingId` is **injective**. `brokkr-core` has
no hasher, so this is injective string composition, not a digest. The condition tag is an **exhaustive**
match with no catch-all, so a new `BarrierCondition` variant forces a compile error rather than a
colliding tag. Proven by three tests (`tests/negative_invariants.rs`): determinism, injectivity over
`(datum, condition)` incl. a separator-collision case, and independence from `classification`/`reason`.

## 3. Structural invariants

**I-2 (no `Deny → Allow`) — HELD, and its proof still proves the right thing.** `BarrierVerdict` is
unchanged. The `compile_fail,E0599` doctest was a **trap risk**: reshaping `BarrierFinding` (Task 3)
made its inline construction miss two fields, which would fail on **E0063** while `compile_fail`
stayed green — proving nothing about I-2 (the same failure mode as the Rev 1.4 `Genome::new` arity
trap). The doctest's construction was updated to the four-field shape, and the emitted error code was
**verified by compiling the snippet standalone: `error[E0599]` and nothing else** — the construction
compiles and only `.into_allow()` fails, so the doctest proves I-2, not a missing field.

**I-5 (the spine depends on nothing internal) — HELD.** `FindingId` is a `string_id!` in `ids`;
`BarrierCondition`/`finding_id()` use only in-crate types and `alloc`. No dependency added;
`brokkr-core/Cargo.toml` `[dependencies]` remains empty; `#![no_std]` preserved.
