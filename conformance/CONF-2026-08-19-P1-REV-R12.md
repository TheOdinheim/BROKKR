## OQGF-P-6.2 — Selection on Independent Evidence

> "A Refined Detector SHALL be activated only if it demonstrates improved detection of the Seeding
> Incident's attack class against an Evaluation Corpus that is independent of the seeding sample. A
> candidate that improves only on the single seeding sample, or that improves detection at the cost
> of degraded coverage elsewhere in the corpus, SHALL be disqualified."

| Field | Content |
|---|---|
| Implementation | `AdaptError` gains `SubstitutedCorpus` (*"the evaluation corpus digest does not match the declared record"*) and `StaleCorpus` (*"the evaluation corpus is not the current version"*), joining `Overfit` and `CoverageRegression`. These give `select` (and, for `StaleCorpus`, `activate`) an **honest** way to refuse a corpus-validity failure — the digest-mismatch and version-mismatch cases §6.12 requires Gate 2 to reject *before measuring* — without the false claim that reusing `Overfit`/`CoverageRegression` would make. The `error_enum!`-generated `Display` impl carries the messages. |
| Proof (the code path, not the type) | `tests/negative_invariants.rs::test_oqgf_p_6_2_corpus_validity_errors_name_the_evidence_not_the_candidate` — exercises `SubstitutedCorpus.to_string()` / `StaleCorpus.to_string()`, asserts each names the **corpus/digest/version** and contains **no** "candidate", and asserts distinctness from each other and from `Overfit`/`CoverageRegression`. **The test that would fail if the gate's honest-message property were removed** (a message reworded to imply a candidate defect fails it). |
| Verdict | **type surface present; enforcement Phase 9 — NOT claimed satisfied.** This revision places the refusal *vocabulary* that makes an honest Gate-2 refusal *possible*; the gate that verifies the corpus digest, checks version equality, and returns these variants is KVASIR (`brokkr-adapt`, Phase 9), which does not exist. P-6.2 is **not** satisfied by this revision. |

**Why this is not a coverage claim.** The verdict is recorded as *vocabulary placed / gate Phase 9*, not satisfied. What this revision is responsible for — that a corpus-validity refusal names the evidence and not the candidate — is the property the named test proves; what it is *not* responsible for — a running Gate 2 — is explicitly deferred to Phase 9.
