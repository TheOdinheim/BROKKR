## 2. FFI honesty (CLAUDE.md §7) — verified, not asserted

- **Non-FIPS stated exactly.** `nm -D | grep -ci fips` = **0**. `CRYPTO_POSTURE` =
  *"CNSA-2.0-aligned; FIPS module validation pending; current build non-FIPS."* No
  stronger claim exists anywhere in the crate.
- **No fabricated algorithm identity.** Every bound symbol is a real exported wolfCrypt
  symbol; the ML-DSA-65 signature size (3309 B) matches FIPS-204 params.
- **Not dilithium (symbol-level).** The linked test binary imports `wc_MlDsaKey_SignCtx`/
  `_VerifyCtx`, `wc_SlhDsaKey_*`, `wc_MlKemKey_*`, and **zero** `dilithium`/`falcon`/
  `kyber` symbols (`nm -u`). `ffi.rs` declares none.
