## 1. Why

Closes **RISK-2026-0003** — the Phase 4 blocker. `brokkr-crypto` had no public-key-only
verifier, so `brokkr-intent`'s `verify_chain` needed the signer's `DualKeyPair` (private
material), leaving OQGF-M-8's "verify using only declared public roots of trust" only
partially satisfied. This revision adds the missing type. SINDRI (Phase 4) verifies chains it
did not sign, using public keys from OQGF-M-1 attestations — it could not, until this landed.

## 2. Ground-truth discovery FIRST (real symbols, real sizes)

Probed before binding (§7), reported in the checkpoint:

| | ML-DSA-65 | SLH-DSA-SHAKE-192s |
|---|---|---|
| Export symbol | `wc_MlDsaKey_ExportPubRaw(key, out, *outLen)` | `wc_SlhDsaKey_ExportPublic(key, out, *outLen)` |
| Import symbol | `wc_MlDsaKey_ImportPubRaw(key, in, inLen)` | `wc_SlhDsaKey_ImportPublic(key, in, inLen)` |
| **Public-key size (probed)** | **1952 B** (`WC_MLDSA_65_PUB_KEY_SIZE`) | **48 B** (`wc_SlhDsaKey_PublicSizeFromParam`) |
| Import prep | `New` → `SetParams(65)` → `ImportPubRaw` | `Init(SLHDSA_SHAKE192S)` → `ImportPublic` |

All four export/import symbols are **exported** in this build; raw export/import is available
(no DER fallback needed). No missing symbol — no STOP-and-report was triggered.

## 3. What was added (brokkr-crypto ONLY; additive)

- **`ffi.rs`** (the sole unsafe file): four new `extern "C"` decls matched to the header
  prototypes; pinned `MLDSA65_PUB_SIZE = 1952`, `SLHDSA192S_PUB_SIZE = 48`; `export_public`
  on `MlDsa65` and `SlhDsaShake192s`; and two **verify-only** wrappers `MlDsa65Public` /
  `SlhDsaShake192sPublic` (import raw public key, `verify`, RAII `Drop`). Each new `unsafe`
  block carries a `// SAFETY:` comment; raw types stay in `ffi.rs`.
- **`sign.rs`** (no unsafe): `DualPublicKey { mldsa, slhdsa }`; `from_public_bytes`
  (length-validated, fail-closed → `MalformedKey`); `verify_dual` (both families required,
  mirrors `DualKeyPair::verify_dual` exactly); `DualKeyPair::public_key_bytes`.
- **`lib.rs`**: re-export `DualPublicKey`.

**No new dependency.** No change to `brokkr-core`, `brokkr-intent`, or `governance/`.
