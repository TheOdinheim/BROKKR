## 0. Precondition — the Deferred-Conjunct Deadline is satisfied

CLAUDE.md §5.1 and BROKKR-ARCH §6.4 forbid wiring the executor to a gate that does not evaluate the action against the chain's current scope and accumulated invariant set. That precondition was discharged by the Phase-4 revision (commit `884958f`): SINDRI's `evaluate` now enforces all four OQGF-M-11 conjuncts (Signal 1, Signal 2, action-in-scope, action-respects-invariants). **Phase 11 is therefore permitted to wire the executor.** No conjunct is enforced by the orchestrator; the orchestrator calls the gate, and the gate enforces.

## 1. Step-0 buildability determination

Every subsystem surface the cycle composes exists and was confirmed by reading the committed source (not the summary). No invention, no gap.

| §5 step | Subsystem | Committed entry point used |
|---|---|---|
| 2 | BIFRÖST | `ContextClearance::clear(ctx, dest, now) -> Result<ClearedContext, BarrierVerdict>` — the provided sole minter of `ClearedContext` (core trait) |
| 3 | MÍMIR | `Reasoner::propose(&ClearedContext, &IntentScope) -> Result<Proposal, ReasonerError>` (core trait) |
| 4 | REGIN | **no per-hop entry point** — `brokkr-genome` exposes only the artifact promotion gate → crate-local `GenomeCheck` port |
| 5 | SINDRI | `CostimulationGate::authorize(&Attestation, &IntentProvenanceChain, Action, now) -> AuthorizationDecision` — provided sole minter of `AuthorizedAction` (core trait) |
| 6 | HÚÐ | `Barrier::evaluate(&BoundaryFlow, now) -> BarrierVerdict` (core trait) |
| 7 | tools | `ToolExecutor::execute(&AuthorizedAction) -> Result<ToolOutcome, ToolError>` |
| 8 | HEIMDALL | `Heimdall::observe(&Observation, now) -> Vec<Detection>` (inherent method, concrete struct) → crate-local `Sentinel` port + `HeimdallSentinel` adapter |
| — | SAGA | `Saga::append(AuditEvent, Dap, Timestamp) -> Result<u64, SagaError>` (inherent) → crate-local `AuditSink` port |
| 9 | EIR / KVASIR | signal recipients; no per-hop call → crate-local `SignalRouter` port |

**Three findings the orchestrator had to accommodate honestly (not gaps — design consequences):**

1. **There is no `Execution` `AuditEvent` variant** (`brokkr-audit::event::AuditEvent` has BarrierCrossing, Authorization, GenomePromotion, Resolution, RiskAcceptance, ToleranceGrant, Signal, DetectorActivation, Proposal, Correction, Erasure — no Execution/Detection). So the orchestrator does **not** fabricate one. The executed action is recorded as the **reconciliation observation** (`Observation::Hop { executed: Some(..) }`) fed to HEIMDALL (§5 step 8), and any **fired detection's Signal** is recorded as `AuditEvent::Signal`. Execution itself is not a SAGA event; that is the committed shape, recorded rather than papered over.
2. **REGIN has no per-hop tool check.** `brokkr-genome` is the artifact promotion gate (`promote`), not a per-hop "is this tool declared, does this hop hold its privilege" lookup. The orchestrator depends on a crate-local `GenomeCheck` port; production backs it from the signed genome. (§5 step 4 is a REGIN responsibility that has no committed per-hop surface yet — the port is the honest seam.)
3. **A successful reasoner crossing carries no recordable verdict.** `clear` returns `Ok(ClearedContext)` on success — it deliberately does not hand back the `Allow`/`AcceptedRisk` verdict (it is the sole minter, evaluating exactly once). Rather than evaluate the barrier twice or fabricate an `Allow`, the orchestrator records the crossing decision only when it **blocks** (from the `Err(verdict)`). A `Proposal` event exists in SAGA **iff** the crossing cleared, so the allowed crossing is implicitly recorded by the presence of the proposal. The OQGF-I-13 "record every allowed crossing" obligation in full is SAGA's, exercised through production wiring; this is stated in the conformance record, not hidden.

## 2. What was built

- **`src/lib.rs`** — the `Orchestrator`, the four crate-local ports, the real `HeimdallSentinel` adapter, the cycle types, the single wall-clock reader, and `execute_hop`.
  - `Orchestrator` holds **every** subsystem behind a trait object: `Box<dyn ContextClearance>`, `Box<dyn Reasoner>`, `Box<dyn GenomeCheck>`, `Box<dyn CostimulationGate>`, `Box<dyn Barrier>`, `Box<dyn ToolExecutor>`, `Box<dyn Sentinel>`, `Box<dyn AuditSink>`, `Box<dyn SignalRouter>`, plus the accountable `Dap`. It does not know which implementations back them — the one composition point in the system.
  - Ports: `GenomeCheck::check`, `Sentinel::observe`, `AuditSink::record`, `SignalRouter::route`. Each is small and reason-carrying (documented why it exists rather than a committed core trait).
  - `HeimdallSentinel(pub Heimdall)` — the one real adapter, proving the `Sentinel` port matches `Heimdall::observe` at compile time.
  - `Orchestrator::now() -> Timestamp` — **the single wall-clock read in the whole system (§4)**. A `pub` associated function reading `SystemTime::now()`; it returns a fresh `Timestamp` and is **never stored** on the orchestrator (I-13).
  - `execute_hop(&self, req: HopRequest, now: Timestamp) -> HopResult` — one iteration of §5 steps 2–8, `now` a call parameter threaded to every time-evaluating subsystem (BIFRÖST clear, SINDRI authorize, HÚÐ evaluate, HEIMDALL observe).
  - `HopResult::{Executed, Denied{stage, reason}, Error}`; `DenialStage::{Bifrost, Genome, Gate, Barrier}` — a denial **names where** it was denied.
- **`src/main.rs`** — a placeholder `main` that prints that the library is wired and production backends are not yet connected. Production wiring (constructing real subsystems, obtaining a Root Intent, driving the loop) is a follow-on; the executor is deliberately not connected to real backends.
- **`tests/orchestrator.rs`** — 10 integration tests, every subsystem a `Send + Sync` test-double spy (atomics + mutexes over `Arc`, never `Cell`/`RefCell`).

**The deny-at-any-gate short-circuit (the heart of the cycle).** `execute_hop` runs step 2 → 8 in order; the first gate to deny returns `HopResult::Denied { stage, .. }` and the later steps do not run:

- BIFRÖST `clear` Err → `Denied{Bifrost}` — the reasoner is never consulted (I-12).
- REGIN `check` Err → record anergic authorization, `Denied{Genome}` — SINDRI never consulted.
- SINDRI `authorize` Anergy → record anergic authorization, observe, `Denied{Gate}` — HÚÐ never consulted, the tool never runs.
- HÚÐ `evaluate` Deny/Quarantine → record crossing, observe, `Denied{Barrier}` — the tool never runs.

Only when all four clear does the tool execute, and only then does HEIMDALL receive `Observation::Hop { executed: Some(..) }` (the first point in the system where an executed action exists) followed by the granted `Observation::Authorization`.

**I-1 holds through the composition.** The orchestrator never constructs an `AuthorizedAction`; it receives one only from `gate.authorize`'s `Granted` arm and hands that exact value to `tool.execute`. There is no other path to the executor.

## 4. Invariants

- **I-1** — the orchestrator mints nothing. `AuthorizedAction` comes only from `gate.authorize` (`Granted`) and flows straight to `tool.execute`. No other executor path exists.
- **I-5 / I-6 / I-9** — `brokkr-cli` is the workspace **leaf**: nothing depends on it (`cargo tree -i` shows only itself). It is the composition root that is *allowed* to depend on `brokkr-reasoner`, `brokkr-tools`, and every governance crate, precisely because nothing governs *it*. The one-way direction is preserved.
- **I-12** — `Reasoner::propose` is reached only through a `ClearedContext` minted by `clear`; on a BIFRÖST deny the reasoner is never called (test 10). An ungoverned context cannot reach the model.
- **I-13** — `now` is a parameter of `execute_hop` and every subsystem call it makes; the orchestrator holds no clock. `Orchestrator::now()` is the single §4 wall-clock read, and it stores nothing.

## 6. What Phase 11 does not do (named, not hidden)

- **No production backends.** `main.rs` is a placeholder; the doubles are the only implementations exercised. Constructing real subsystems and driving the loop is follow-on wiring.
- **Execution is not a SAGA event.** Recorded honestly (§1 finding 1): the executed action is the reconciliation observation to HEIMDALL; there is no `AuditEvent::Execution`.
- **Per-hop REGIN and full OQGF-I-13 allow-crossing recording** are seams/production concerns (§1 findings 2–3), stated in the conformance record.
- **The Root Intent construction (§5 step 1)** is the caller's, before the loop — `execute_hop` receives the chain, it does not build the Root Intent.
