**What I-13 forbids:** a **held** clock — the current time stored as construction state. The
resolver is *configuration* and may be construction state; the current time may not.

**SINDRI's committed shape (before):**
- `struct Sindri<R> { resolver: R, now: Timestamp }` — the held clock is the `now` field.
- `Sindri::new(resolver, now: Timestamp)` — injected the time at construction.
- **`self.now` used once:** `signal_2`, `verify_chain_public(root, entries, &root_pub, &hop_refs,
  self.now)`.
- `evaluate(&self, identity, chain, _action)` — 3 params; the arity break against the new 4-param
  trait.
- A doc block *"Why `now` is held in state"* explicitly justified the held clock against the
  pre-Rev-1.15 trait — now obsolete and contradicting I-13.

**How the old expiry test supplied time (the test that agreed with the defect):**
`test_oqgf_m_14_expired_chain_is_anergy` built `Sindri::new(registry, Timestamp(20_000))` — `now`
fixed at construction, `> expiry` — and evaluated **once**. A single evaluation cannot distinguish
a stale held clock from a per-call one; the test passed on the held clock because it shared the
defect's assumption.

## Task 1 — remove the held clock

- Deleted the `now` field from `Sindri` and the `now` parameter from `Sindri::new`. **Confirmed no
  other field removed:** the resolver is configuration and stays; `struct Sindri { resolver: R }`.
- `evaluate` takes `now: Timestamp` (4th param, per the trait) and threads it to
  `signal_2(chain, now)`, which passes it to `verify_chain_public`. Every path that previously read
  `self.now` now uses the parameter (there was exactly one such path).
- Rewrote the obsolete *"Why `now` is held"* doc block to *"`now` arrives per call, and is never
  held (I-13)"*, citing the defeated-for-four-phases history (RISK-2026-0006).

**CONFIRMED — held-clock grep in `brokkr-gate/src` returns empty, with a pattern broad enough to
catch a method as well as a field** (because `self.now` alone missed BIFRÖST's `self.now()`
earlier, which is how the second instance survived):
- `self\.now` → **empty** (catches both `self.now` and `self.now()`).
- `Self { … now … }` → **empty** (nothing stores a clock at construction).
- The only two `now: Timestamp` occurrences are the `evaluate` and `signal_2` **parameters** —
  exactly what I-13 requires. `struct Sindri` has a single field, `resolver`.

## Task 3 — the test that agreed with the defect

Rewrote `test_oqgf_m_14_expired_chain_is_anergy` → **`test_oqgf_m_14_i13_expiry_is_evaluated_
against_call_time_not_a_held_clock`** (named for both OQGF-M-14 and I-13). The decisive shape:

- Construct **one** `Sindri` (no clock).
- Evaluate the **same** chain (expiry 10 000) **twice** with the **same** instance: `now = 500`
  (before expiry) → **Granted**; `now = 20 000` (after expiry) → **`ChainExpired`**.

**Why the new test catches the defect and the old one could not.** A held clock is fixed at
construction, so from one instance it can produce only **one** verdict for a given chain — two
different verdicts from one instance is impossible under the pre-I-13 design, so this test cannot
pass against a stored clock. The old test injected `now = 20_000` at construction and evaluated
once; because it never advanced the time, it could not tell a stale held clock from a per-call one,
and it passed on the held clock *because it agreed with it*. Fixing the signature does not fix that
test — the test itself had to change to have a way to fail.

The other nine tests keep their prior meaning; each `authorize` call now receives the call-site
`now` (`Timestamp(500)`, the value formerly held) so behaviour is preserved, and each `Sindri::new`
drops its second argument.
